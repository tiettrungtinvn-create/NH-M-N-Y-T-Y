Nhìn thấy cách hàng đợi hoạt động

Mô phỏng JavaScript theo thuật toán của các lớp C++ trong dự án. Dùng một phòng khám mẫu để tập trung vào thứ tự lấy phần tử.

Kịch bản 20 bước: FIFO → quay vòng → hàng đầy → cấp cứu → lịch sử.
Đây là độ ưu tiên trong mã C++; giao diện tiếp nhận dùng cấp độ phân loại ngược chiều.
Bấm “Chạy kịch bản mẫu” hoặc tự tiếp nhận bệnh nhân để bắt đầu.

01 · Queue mảng vòng

FIFO · Mức 1

Bệnh nhân thường được thêm ở cuối, lấy ở đầu theo thứ tự đến.

front = 0rear = 0count = 0capacity = 4
front: vị trí lấy tiếp theorear: vị trí thêm tiếp theo

int cuoi = (dau + dem) % MAX_HANG_DOI;
a[cuoi] = bn;
dem++;
// Khi lấy: dau = (dau + 1) % MAX_HANG_DOI; dem--;
Thuật toán: code/include/HangDoi.h · Bản minh họa có 4 ô; mã C++ có 100 ô cố định.

02 · Priority Queue

Ưu tiên · Mức 2–5

Danh sách liên kết có thứ tự: mức lớn hơn ở trước; cùng mức giữ thứ tự đến.

bool operator<(const BenhNhan& o) const {
  if (doUuTien != o.doUuTien) return doUuTien < o.doUuTien;
  return soThuTu > o.soThuTu;
}

Chèn nút vào đúng vị trí trong danh sách; lấy nút đầu tiên khi gọi khám.

Thuật toán: code/include/HangUuTien.h · So sánh: code/include/BenhNhan.h

03 · Deque lịch sử gọi

Lượt vừa gọi được thêm vào cuối Deque; khi đầy, bỏ lượt cũ nhất ở đầu. Bản mẫu giữ 5 lượt, mã C++ giữ 100 lượt.
