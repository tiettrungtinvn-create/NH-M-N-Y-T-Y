# Báo cáo LaTeX CareQueue

Tải nội dung thư mục gốc repository lên Overleaf (New Project → Upload Project), mở `bao_cao.tex`, chọn **XeLaTeX** và đặt tệp này làm Main document. Cần giữ nguyên cây thư mục vì phần phụ lục đọc mã nguồn qua đường dẫn tương đối.

Trước khi nộp, sửa các mục trong trang bìa, điền liên kết GitHub/Jira thật, bổ sung ảnh/số liệu của nhóm, biên dịch và kiểm tra PDF có **40–50 trang nội dung thực**. Nếu vượt giới hạn, chuyển mã nguồn đầy đủ sang phụ lục riêng hoặc rút gọn listing; nếu thiếu, bổ sung phân tích thuật toán, sơ đồ và kết quả thực nghiệm thật. Không chèn trang trắng để đủ số trang.

Đã có bản PDF tham khảo 44 trang ở `docs/BAO_CAO_CHINH_SUA.pdf`. Nhóm vẫn cần biên dịch trực tiếp từ `bao_cao.tex` bằng XeLaTeX và rà soát bản PDF cuối trước khi nộp.
